# Расширение браузера RehubPro CRM

Chrome-расширение (Manifest V3) для WhatsApp Web, Telegram Web (версии K и A) и Instagram Direct. Сотрудник один раз входит в CRM и отмечает нужные чаты галочкой «Отслеживать». После этого новые сообщения этих чатов сами передаются в выбранное обращение, пока чат открыт в браузере. Остальные чаты, в том числе личные, не передаются.

## Как пользоваться

1. Установите расширение (см. ниже) и нажмите на его значок.
2. Нажмите «Войти в RehubPro CRM». Откроется окно CRM: войдите и нажмите «Разрешить доступ». Если вы состоите в нескольких компаниях, выберите нужную.
3. Откройте чат в мессенджере и нажмите на значок расширения:
   - для WhatsApp обращение подбирается по номеру собеседника, если номер есть у клиента или контактного лица в CRM;
   - если совпадений несколько или нет, выберите обращение поиском;
   - поставьте галочку «Отслеживать этот чат».
4. Внизу страницы мессенджера появится метка «CRM: отслеживается». Новые сообщения передаются через несколько секунд после появления.

Подключённые браузеры видны в CRM: «Настройки → Расширение браузера». Там же доступ можно отозвать. При отключении сотрудника доступ пропадает сразу.

## Сборка и установка для разработки

```bash
cd extension
npm ci
npm run build                                   # CRM на http://127.0.0.1:3100
CRM_URL=https://crm.example.kz npm run build    # сборка для рабочего адреса
```

Адрес CRM задаётся при сборке и попадает в манифест, поэтому сотрудник его не вводит.

В Chrome откройте `chrome://extensions`, включите режим разработчика и нажмите «Загрузить распакованное расширение» → папка `extension/dist`. Благодаря полю `key` в манифесте ID расширения постоянный: `bmpbpohmpkpikemmocmchnhccmcneolc`. CRM разрешает вход только расширениям из `CRM_EXTENSION_IDS`, по умолчанию — этому ID.

## Публикация

- **Chrome Web Store (рекомендуется).** Аккаунт разработчика (разовый взнос $5), загрузка zip из `extension/dist` без поля `key`, политика конфиденциальности и описание использования данных. Видимость «Не в списке» — установка только по ссылке, которую вы даёте центрам. Обновления приходят автоматически. Магазин присваивает свой ID — добавьте его в `CRM_EXTENSION_IDS`.
- **Принудительная установка через политики Chrome** — если у центров управляемые компьютеры (Google Workspace / групповые политики).
- Раздать файл с сайта нельзя: Chrome на Windows и macOS не устанавливает расширения не из магазина. Исключение — режим разработчика, но он для проверки, а не для работы.

Перед публикацией проверьте правила WhatsApp, Telegram, Instagram и Chrome Web Store: у магазина строгие требования к расширениям, которые читают переписку.

## Устройство

- `src/adapters/*` — чтение страниц (интерфейс `ConversationReader`), выбор адаптера в `adapters/index.ts`.
- `src/content.ts` — следит за изменениями страницы и отправляет текущий чат в фоновый worker; показывает метку.
- `src/background.ts` — проверяет, отслеживается ли чат, и передаёт сообщения в CRM. Ключ повтора вычисляется из содержимого фрагмента, поэтому повтор не создаёт дублей.
- `src/popup.ts` — статус чата и галочка «Отслеживать»; `src/settings.ts` — вход через `chrome.identity.launchWebAuthFlow`, который выполняет фоновый worker (popup закрывается при открытии окна входа).
- `static/icons` — логотип RehubPro из `rehubpro-main/static/logo/logo.png`.
- API CRM: `/api/ext/session/`, `leads/`, `match/`, `conversations/lookup|track|untrack/`, `imports/`. Только `Authorization: Bearer`, без cookie.

## Ограничения прототипа

- Передаются только сообщения, загруженные на странице, и только пока вкладка мессенджера открыта.
- WhatsApp Web: идентификаторы и время — из `data-id` и `data-pre-plain-text`; номер собеседника — из идентификатора чата.
- Telegram Web K: идентификаторы и время — из `data-mid` и `data-timestamp`; версия A — без времени. Телефон собеседника не используется: подбор обращения поиском.
- Instagram: нет времени и идентификаторов сообщений, направление определяется по положению на экране.
- Вложения не передаются, отмечается только их наличие.
- Проверено в Chrome 157 на настоящих страницах web.telegram.org и web.whatsapp.com с синтетическими сообщениями: вход ключом, отслеживание, подбор по номеру, автопередача и отсутствие дублей. Разметку реальных чатов нужно проверить на тестовых аккаунтах.
