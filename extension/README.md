# Расширение браузера RehubPro CRM

Chrome-расширение (Manifest V3) передаёт выбранный диалог WhatsApp Web или Instagram Direct в обращение CRM. Сотрудник видит предпросмотр, выбирает обращение и сам нажимает «Передать в CRM». Автоматического сбора всех диалогов нет.

## Сборка и установка

```bash
cd extension
npm ci
npm run build
```

В Chrome откройте `chrome://extensions`, включите режим разработчика и загрузите папку `extension/dist`.

В CRM: «Настройки → Расширение браузера → Выдать ключ». Ключ показывается один раз. В расширении откройте «Настройки», укажите адрес CRM и ключ; Chrome запросит доступ только к этому адресу.

## Устройство

- `src/adapters/*` — адаптеры страниц (интерфейс `ConversationReader`), выбор в `adapters/index.ts`. Новый мессенджер — новый адаптер.
- `src/content.ts` — читает открытый диалог по запросу popup; загружается через `content-loader.js`, потому что content script MV3 не может быть модулем.
- `src/popup.ts` — предпросмотр, поиск обращения, отправка. Ключ повтора сохраняется до подтверждения: повтор после потери ответа не создаёт дублей.
- API: `GET /api/ext/session/`, `GET /api/ext/leads/?q=`, `POST /api/ext/imports/`. Только заголовок `Authorization: Bearer crx_…`, без cookie.

## Ограничения прототипа

- Передаются только сообщения, загруженные на странице. Для более ранних сообщений прокрутите диалог.
- WhatsApp Web: идентификаторы и время берутся из атрибутов `data-id` и `data-pre-plain-text`. Вложения не передаются, отмечается только их наличие.
- Instagram: нет времени и идентификаторов сообщений, направление определяется по положению на экране. Повтор того же фрагмента дублей не создаёт, изменённый фрагмент может.
- Селекторы проверены только на синтетической разметке. Перед использованием проверьте на тестовых аккаунтах: структура страниц мессенджеров меняется без предупреждения.
- Пароли, cookie и сессии мессенджеров не передаются. Перед распространением проверьте правила WhatsApp, Instagram и Chrome Web Store.
